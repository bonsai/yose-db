# 名簿スナップショット

1団体1年の前座名簿をこのディレクトリに置きます（下記形式）。推計モデルと
生成方法は `../README.md` を参照。

```json
{
  "organization": "落語協会",
  "year": 2026,
  "entries": [{"name": "○○", "rank": "zenza"}, {"name": "××", "rank": "futatsume"}],
  "promotions": {"2024": 12, "2025": 10}
}
```

- ファイルは `docs/` 等に置かず `lists/` 直下に1団体1ファイルで追加してください。
  `*_meta` などの作業ファイルは置かないでください。
- 実測値でないものは配置せず（推測禁止）、未収集の年は `promotions` から proxy 推計されます。
